🧩 STEG 1 – SKAPA NAVIGATION (NavLink)

components/Navigation.jsx

import { NavLink } from "react-router-dom";

function Navigation() {
  return (
    <nav>
      <NavLink to="/" end>Home</NavLink>
      {" | "}
      <NavLink to="/about">About</NavLink>
      {" | "}
      <NavLink to="/users">Users</NavLink>
    </nav>
  );
}

export default Navigation;


🗣️ TALARMANUS
“NavLink är Link med superkrafter.”

“Den vet om länken är aktiv.”

“React Router lägger automatiskt till en ‘active’-klass.”

“Detta är perfekt för menyer.”

🗣️
“end betyder: matcha exakt.”

“Utan end hade Home varit aktiv även på /about.”

🧩 Steg 2 – Layout + Outlet
MainLayout.jsx

import { Outlet } from "react-router-dom";
import Navigation from "../components/Navigation";

function MainLayout() {
  return (
    <>
      <Navigation />
      <main>
        <Outlet />
      </main>
    </>
  );
}

export default MainLayout;


“Layouts är en av de viktigaste byggstenarna i större appar.”

“En layout är inte en sida – det är ett skal runt sidor.”

“Navigation renderas bara en gång.”

“Navigationen ska alltid synas, men innehållet i mitten ska kunna bytas.”
“Navigation är en återanvändbar UI-del – därför ska den ligga i components.”
“Layouten sätter ihop strukturen, men äger inte detaljerna.”

“Det är exakt det MainLayout gör.”

🧠 OUTLET – VARFÖR?

🗣️ TALARMANUS
“Outlet är en platshållare.”

“Det är här React Router stoppar in den route som matchar URL:en.”

“Man kan tänka Outlet som:
👉 ‘här ska barn-routen visas’.”

“Utan Outlet finns det ingen plats för child/nested-routes.”

🧩 Steg 3 – Nested routes + INDEX ROUTE i App.jsx

import { Routes, Route } from "react-router-dom";
import MainLayout from "./layouts/MainLayout";

import Home from "./pages/Home";
import About from "./pages/About";
import Users from "./pages/Users";
import UserProfile from "./pages/UserProfile";
import NotFound from "./pages/NotFound";

function App() {
  return (
    <Routes>
      <Route path="/" element={<MainLayout />}>
        <Route index element={<Home />} />
        <Route path="about" element={<About />} />
        <Route path="users" element={<Users />} />
        <Route path="users/:id" element={<UserProfile />} />
      </Route>

      <Route path="*" element={<NotFound />} />
    </Routes>
  );
}

export default App;

🗣️ NESTED ROUTES

“När vi nestar routes betyder det att routes delar layout.”

“Allt som ligger inuti/under /-routen använder MainLayout.”

“Navigationen laddas alltså inte om – bara innehållet i Outlet byts.”

🧠 INDEX ROUTE

<Route index element={<Home />} />

🗣️ TALARMANUS
“Index betyder: detta är startsidan för layouten.”

“När URL:en exakt matchar / så visas Home.”

“Index är alltså samma sak som path='' – men mycket tydligare.”

“Det gör koden lättare att läsa och förstå.”

🧠 VIKTIG REGEL – CHILD PATHS

<Route path="about" element={<About />} />


🗣️ TALARMANUS
“Observera att child-paths inte börjar med /.”

“about blir automatiskt /about eftersom den är barn till /.”

“Om du skriver /about här – då bryter du nesting.”

“Det här är ett vanligt nybörjarfel.”

🔀 DYNAMISKA ROUTES (URL-PARAMETRAR)

<Route path="users/:id" element={<UserProfile />} />


🗣️ TALARMANUS
“Här säger vi: URL:en innehåller data.”

“:id betyder att det här är en variabel del av URL:en.”

“/users/1
/users/42
/users/mandus”

“Alla matchar samma route – men med olika id.”

🧩 Steg 4 – Dynamiska routes (useParams)
UserProfile.jsx

import { useParams } from "react-router-dom";

function UserProfile() {
  const { id } = useParams();

  return <h2>User profile: {id}</h2>;
}

export default UserProfile;

🗣️ TALARMANUS
"URL:en innehåller data."

“useParams läser data från URL:en.”

“Det här är hur routing och data möts.”

“URL:en styr vad som visas – utan extra state.”

--------------------------------------------------

🧩 Steg 5 – Programmatisk navigation - Users.jsx

import { useNavigate } from "react-router-dom";

function Users() {
  const navigate = useNavigate();

  return (
    <>
      <h2>Users</h2>
      <button onClick={() => navigate("/users/123")}>
        Go to user 123
      </button>
    </>
  );
}

export default Users;

🗣️ TALARMANUS

“useNavigate används när navigation inte sker via klick på länk.”

“Till exempel efter submit, login eller redirect.”

“Detta ersätter window.location – men utan reload.”

“useNavigate används efter events.”
